## 0.9 — build isolation and direct free registration, 3 November 2026

Fixed the 0.8 build script that wrote the same live artifact to both local/live filenames. Builds now default to local, validate explicit local/live selection, use separate output directories and Android install IDs, and update only the selected APK after checks pass. Live Firebase configuration is parsed structurally and must match the Android package; live builds reject a configured transaction-service URL and disallow cleartext traffic. Local and live accounts/caches cannot share an install.

Free joins now use the Android Firestore client transaction, with rules requiring an immutable entry plus exactly one seat in the same commit. No wallet write or local operations server is involved. Duplicate retries return the existing entry. A real-device-emulator test exposed a read-only transaction returning cached confirmation while offline; an explicit server read now precedes success feedback. Paid entry/deposit controls explain their unavailable state in the live preview. Staff operation buttons use the operation's own busy/error state, avoiding a second busy flag and recovery effect.

Verification details and limitations are in verification/stability-v0.9/REVIEW.md. Complete pilot scope is tracked in IMPLEMENTATION-CHECKLIST.md. Production rules/index deployment, owner phone acceptance, rooms, results and all unfinished finance/roadmap items remain outstanding. No real money, billing or production deployment was enabled.
